# 悬赏发布页面功能说明

## 页面概述

悬赏发布页面（CreateBounty.vue）是IT服务平台的核心功能之一，允许用户发布技术需求悬赏，寻找合适的开发者来完成项目。

## 主要功能

### 1. 基本信息填写
- **悬赏标题**：10-100字符，简洁明了地描述需求
- **需求描述**：50-2000字符，详细描述项目需求
- **技术分类**：选择项目所属的技术领域
- **项目标签**：添加相关标签，支持热门标签快速选择

### 2. 预算与时间设置
- **预算类型**：支持固定价格和预算范围两种模式
- **项目预算**：设置项目预算金额（100-1,000,000元）
- **截止时间**：设置悬赏截止时间，不能早于当前时间

### 3. 技能要求
- **技能标签**：添加项目所需的技术技能
- **热门技能**：提供常用技能快速选择
- **最多支持15个技能标签**

### 4. 项目设置
- **工作方式**：支持远程工作、现场工作、混合模式
- **项目优先级**：普通、紧急、非常紧急三个级别

### 5. 详细需求说明
- **富文本编辑器**：支持Markdown语法
- **工具栏**：提供标题、粗体、斜体、代码、列表等格式化工具
- **最多5000字符**

### 6. 附件上传
- **支持格式**：PDF、DOC、DOCX、JPG、PNG、GIF
- **文件大小**：单个文件不超过10MB
- **数量限制**：最多上传5个文件

### 7. 联系方式
- **联系电话**：必填，支持手机号格式验证
- **联系邮箱**：必填，支持邮箱格式验证
- **其他联系方式**：可选，如微信、QQ等

### 8. 发布设置
- **公开投标**：允许所有开发者查看和投标
- **作品集要求**：要求投标者提供作品集
- **自动通知**：自动通知匹配的开发者
- **定时发布**：支持设置定时发布时间

## 技术特性

### 1. 表单验证
- 使用Ant Design Vue的表单验证规则
- 实时验证用户输入
- 友好的错误提示

### 2. 草稿功能
- **自动保存**：每30秒自动保存草稿到本地存储
- **手动保存**：支持手动保存草稿到服务器
- **草稿恢复**：页面刷新后自动恢复草稿内容

### 3. 预览功能
- **实时预览**：查看发布后的悬赏展示效果
- **Markdown渲染**：支持需求说明的Markdown格式预览

### 4. 响应式设计
- **移动端适配**：支持手机和平板设备
- **布局自适应**：根据屏幕尺寸调整布局

### 5. API集成
- **RESTful API**：与后端API完全集成
- **文件上传**：支持附件上传到服务器
- **错误处理**：完善的错误处理和用户提示

## API接口

### 悬赏相关接口
- `POST /api/v1/bounties` - 发布悬赏
- `PUT /api/v1/bounties/:id` - 更新悬赏
- `GET /api/v1/bounties/categories` - 获取分类
- `GET /api/v1/bounties/popular-skills` - 获取热门技能
- `POST /api/v1/bounties/draft` - 保存草稿
- `POST /api/v1/upload/attachment` - 上传附件

## 使用流程

1. **填写基本信息**：输入标题、描述、选择分类和标签
2. **设置预算时间**：选择预算类型、输入金额、设置截止时间
3. **添加技能要求**：选择项目所需的技术技能
4. **配置项目设置**：选择工作方式和优先级
5. **编写详细需求**：使用富文本编辑器详细描述需求
6. **上传相关附件**：上传需求文档、设计稿等资料
7. **填写联系方式**：提供有效的联系电话和邮箱
8. **配置发布设置**：选择发布选项
9. **预览和发布**：预览悬赏内容，确认后发布

## 注意事项

1. **必填字段**：标题、描述、分类、预算、截止时间、技能、需求说明、联系方式为必填
2. **字符限制**：各字段都有相应的字符长度限制
3. **文件限制**：附件有格式和大小限制
4. **时间限制**：截止时间不能早于当前时间
5. **标签数量**：项目标签最多8个，技能标签最多15个

## 扩展功能

1. **模板功能**：可以保存常用的悬赏模板
2. **历史记录**：查看之前发布的悬赏
3. **批量操作**：支持批量管理悬赏
4. **数据统计**：查看悬赏的浏览量、申请数等统计数据
5. **消息通知**：实时接收投标和消息通知

这个悬赏发布页面提供了完整的功能和良好的用户体验，符合现代Web应用的设计标准。
