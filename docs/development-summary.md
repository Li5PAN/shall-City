# IT服务平台开发指南总结

## 📋 项目概述

基于Spring Boot + Vue 3的IT服务平台，解决传统IT服务供需匹配低效、流程碎片化等问题。支持普通用户、服务提供方、管理员三种角色的完整业务流程。

## 🏗️ 技术架构

### 前端技术栈
- **框架**: Vue 3 + Composition API
- **构建**: Vite
- **路由**: Vue Router 4 (模块化配置)
- **状态管理**: Pinia
- **UI组件**: Element Plus / Ant Design Vue
- **HTTP**: Axios
- **样式**: SCSS/Less

### 项目结构
```
src/
├── api/           # API接口层
├── components/    # 组件库
├── layouts/       # 布局模板
├── pages/         # 页面组件
├── router/        # 路由配置
│   └── modules/   # 路由模块
├── stores/        # 状态管理
└── utils/         # 工具函数
```

## 🎯 核心功能模块

### 1. 普通用户模块 (`/user`)
- **资讯大厅**: 浏览技术文章、分类筛选、点赞收藏
- **文章管理**: 发布文章、编辑草稿、内容审核
- **论坛讨论**: 技术问答、帖子回复、社区互动
- **服务购买**: 浏览服务、下单支付、订单跟踪
- **需求悬赏**: 发布需求、设置赏金、接单管理
- **个人中心**: 信息管理、关注粉丝、消息通知

### 2. 服务提供方模块 (`/provider`)
- **服务管理**: 创建服务、定价策略、上架审核
- **订单处理**: 接单管理、状态更新、交付确认
- **数据统计**: 收入分析、订单趋势、交易记录

### 3. 管理员模块 (`/admin`)
- **用户管理**: 角色权限、账户状态、用户升级
- **内容审核**: 文章审核、服务审核、论坛管理
- **订单仲裁**: 申诉处理、纠纷解决、退款管理
- **平台运营**: 数据统计、系统日志、公告发布

## 🛣️ 路由设计

### 路由模块化
采用模块化路由配置，便于维护和扩展：

```javascript
// 路由模块
src/router/modules/
├── router.js    # 公共路由
├── user.js      # 用户路由
├── provider.js  # 服务商路由
└── admin.js     # 管理员路由
```

### 权限控制
- **认证守卫**: 检查登录状态
- **角色守卫**: 验证用户权限
- **访客限制**: 已登录用户访问限制

## 📱 页面设计规范

### 布局系统
- **UserLayout**: 普通用户布局（侧边导航 + 主内容）
- **ProviderLayout**: 服务商布局（数据看板风格）
- **AdminLayout**: 管理后台布局（管理界面风格）
- **GuestLayout**: 访客布局（登录注册页面）

### 组件规范
- **命名**: PascalCase，功能描述性
- **结构**: Template + Script Setup + Scoped Style
- **Props**: 类型验证 + 默认值
- **事件**: 统一命名规范

### 响应式设计
- **移动端**: 单列布局，侧边栏折叠
- **平板端**: 两列布局，功能简化
- **桌面端**: 多列布局，完整功能

## 🔌 API接口规范

### 接口设计
- **基础URL**: `/api/v1`
- **认证**: Bearer Token
- **格式**: 统一JSON响应
- **状态码**: RESTful规范

### 核心接口
- **认证模块**: 登录、注册、Token刷新
- **用户模块**: 信息管理、关注系统
- **内容模块**: 文章、服务、悬赏CRUD
- **订单模块**: 创建、支付、状态管理
- **管理模块**: 审核、统计、系统管理

## 🎯 核心业务流程

### 1. 需求悬赏流程
```
用户发布需求 → 填写标准化模板 → 设置赏金 → 
服务商浏览需求 → 提交方案报价 → 用户选择服务商 → 
签订合同 → 开始开发 → 交付验收 → 支付赏金
```

### 2. 服务购买流程
```
用户浏览服务 → 查看详情评价 → 下单支付 → 
服务商接单 → 沟通需求 → 开始服务 → 
交付成果 → 用户确认 → 完成订单 → 评价反馈
```

### 3. 内容审核流程
```
用户提交内容 → 系统初审 → 人工审核 → 
审核通过发布 / 驳回修改 → 内容上线 → 
用户反馈 → 持续优化
```
